# תעלומת הפיצות – פריזמה

חדר בריחה דיגיטלי לכיתה ז׳ (שער עצמאות): ארגון נתונים בטבלת שכיחויות מאוזנת, שכיח, סכום השכיחויות ושינוי השכיח כשמגיעים נתונים חדשים. כל דלת נפתחת בקוד שנגזר מהטבלה.

- **רמה 1:** סופרים את ההודעות ובונים את הטבלה.
- **רמה 2:** בודקים ומתקנים טבלה שמילא ועד הכיתה. השגיאות בה מקזזות זו את זו, כך שהסכום יוצא נכון. אחר כך מסיקים אם התלמידים שעוד לא ענו יכולים לשנות את השכיח.
- **עיצוב:** פיצרייה חמה בכל המסכים. בפתיחה ובסיום מופיעה הטבחית, במשימות יש פנים פיצרייה ואיורי פיצה. הפתקים בנויים ב־HTML ו־CSS.
- `index.html` – קובץ אחד עצמאי. הפונט, הלוגו, האייקונים והצלילים (מתיקיית prisma), הרקעים ואיורי הפיצה מוטמעים בו. אין תלות ב־Google Drive.
- **פרסום:** Settings → Pages → Branch `main` / root. אתר סטטי, ללא שרת.
