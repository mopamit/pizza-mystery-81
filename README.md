# תעלומת הפיצות – פריזמה

חדר בריחה דיגיטלי לכיתה ז׳ (שער עצמאות): ארגון נתונים בטבלת שכיחויות מאוזנת, שכיח, סכום השכיחויות ושינוי השכיח כשמגיעים נתונים חדשים. כל דלת נפתחת בקוד שנגזר מהטבלה.

- `index.html` – קובץ אחד עצמאי. הפונט, הלוגו, האייקונים והצלילים (מתיקיית prisma) מוטמעים בתוכו, ואין תלות ב־Google Drive.
- פרסום: Settings → Pages → Branch `main` / root. אתר סטטי, ללא שרת.
